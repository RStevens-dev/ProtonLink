# Watch fonts

IBM Plex Mono Medium is the native substitute for the browser simulator's
platform-dependent `ui-monospace` and canvas `monospace` faces. The source and
license are available in [Google Fonts](https://github.com/google/fonts/tree/main/ofl/ibmplexmono).
The bundled bitmap subsets are built with `lv_font_conv` 1.5.3, in LVGL format,
4 bpp, without compression or kerning. The command and glyph list for each
subset appear at the top of its generated C file.

Montserrat remains available for interface icons, proportional labels, and
fallback glyphs.
