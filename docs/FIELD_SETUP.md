# Batch 2 — Field functionality

Field setup in development tools manages module order and visibility, gestures, favorites, named track collections, equipment preferences and separate local pack metadata profiles. Playlists are selectable track collections, not automatic sequencing; upstream provides no verified track-completion event. Search is in the configuration panel. Audio presets and temporary reduction are on the watch Audio Presets page; reduction restore is explicit, not timed. Equipment presets use existing supported commands and never turn on pack power or smoke. Unavailable settings are skipped; commands are serial and stop on reported failure. Startup checks use observed telemetry and local policy, not a real safety certification. Pack profiles are metadata/host labels only; simulator does not connect to hardware. All settings are included in the existing JSON backup. Native firmware remains outstanding.
