# Industrial Quick Control

Opt-in saved main-screen mode. System Output, Discharge Effects and Auxiliary Audio are master, effects and music volume, not energy regulation. Existing 600 ms debouncing and incremental volume commands are reused. START/STOP/VENT require a one-second hold; release or movement cancels. Status area opens the existing menu hub. Tap four lights for PKE monitor and tap again to return. Hold 1.5 seconds to lock; unlock retains the existing hold/release/swipe gesture and returns to configured main mode. PKE is still the default locked face. Quick and monitor are exempt from inactivity lock; submenu timeout returns to Quick. Link and command guards remain active. This is a browser simulator, not native firmware. Actual layout and physical touch behavior require testing.


## Auxiliary transport

Compact fourth module below channel adjusters. Green readout shows actual GPStar ID and effective title from the existing track library. Tap readout or LIST for the same named track database; selecting a track returns to field control after simulated command success. START/STOP, PAUSE/RESUME, previous and next reuse existing music intents. Music controls use taps, pack switches retain holds. Offline/busy transport writes are disabled. No new API endpoints.
