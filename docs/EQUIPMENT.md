# Gen 1 equipment fidelity audit

Sources: [PCB](https://github.com/gpstar81/GPStar-proton-pack/blob/main/docs/PACK_PCB.md), [Attenuator](https://github.com/gpstar81/GPStar-proton-pack/blob/main/docs/ATTENUATOR.md), [wireless operation](https://github.com/gpstar81/GPStar-proton-pack/blob/main/docs/WIRELESS_OPERATION.md), [lid](https://github.com/gpstar81/GPStar-proton-pack/blob/main/docs/CYCLOTRON_LID.md), [DIY pack](https://github.com/gpstar81/GPStar-proton-pack/blob/main/docs/DIY_PACK.md), [Webhandler](https://github.com/gpstar81/GPStar-proton-pack/blob/main/source/Attenuator/include/Webhandler.h), [System](https://github.com/gpstar81/GPStar-proton-pack/blob/main/source/Attenuator/include/System.h), [Serial](https://github.com/gpstar81/GPStar-proton-pack/blob/main/source/Attenuator/include/Serial.h).

Watch uses HTTP/WS via ESP32 Attenuator; GPStar I pack RX1/TX1 is the gateway serial port, RX2/TX2 is the wand serial port. Ribbon alarm SW6 is not the hose or lid detector. The lid pogo pins carry LED power/data and lid detection; stock lid has four red lenses with 12 LEDs. Stock power cell has 13 LEDs. RGB, smoke, motorized cyclotron and inner LEDs are optional. Stock is the preview default, not a claim about the owner's modifications. Upgraded preview uses illustrative 15/36 counts.

The simulator separates Wi-Fi loss, gateway power and serial sync, returns empty status when reachable but unsynced, and blocks watch commands until equipment status is available. Pack/wand power, barrel, ribbon, lid, ramping and operating mode are independent controls. Stream eligibility uses a conservative subset of the upstream checks; exact capabilities are firmware dependent. Theme changes require idle pack and wand. Symbolic serial event names reflect selected verified handlers; the console does not emulate byte-level packets or exact asynchronous timing. A_VOLUME_SYNC represents pack-reported volume confirmation distinct from HTTP acknowledgement. Other commands remain local state transitions.

Cyclotron animation uses reported state multiplier rather than wand level; physical lens color and digital warning colors are separate. Power cell is a visual sequence rather than a level gauge. Animation timing, geometry, ramp duration and alarm response remain approximations; physical hardware and firmware version are unverified. No real device traffic or configuration writes.
