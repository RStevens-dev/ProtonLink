# Roadmap

- v0.1: offline simulator, documentation, branding handoff.
- v0.2: complete UI navigation, native-resolution layout regression, face selection, gesture and accessibility testing.
- v0.3: scenario fixtures, capability model, transport contract, error handling, track library and favorites.
- v0.4: Attenuator adapter, mDNS/IP fallback, WebSocket/polling, reconciliation and mock-server integration.
- v0.5: workshop configuration previews, lighting controls, presets and rollback/partial-failure feedback.
- v0.6: event history, configurable favorites, watch settings and offline voice feasibility.
- v0.7: board driver bring-up, LVGL port, power management and flashable firmware.
- v0.8: physical Gen 1 Attenuator compatibility tests and performance tuning.
- v0.9: reliability, documentation, release packaging and user acceptance.
- v1.0: stable release after hardware verification.

No dates or hardware availability are assumed. Do not require GPStar II or a pack firmware upgrade merely to develop the simulator.
