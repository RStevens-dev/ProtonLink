# Branding

Final owner-selected design: industrial rectangular steel enclosure, asymmetrical yellow cable, caged red/orange beacon, white PROTON / red LINK lettering and yellow/black diagonal stripes. Use the owner's final PNG for previews and the final Inkscape SVG as the editable master. Earlier drafts are superseded.

Expected paths: assets/branding/ProtonLink.svg and assets/branding/ProtonLink.png. The original SVG is approximately 29 MB with embedded textures. Preserve it unchanged; do not flatten or rewrite the layers. Upload these original files if absent. Keep the top three weathering groups independently adjustable. The clean base must remain convincing with weathering hidden. Inkscape Layers and Objects (Ctrl+Shift+L) allows independent opacity/visibility.

Material sources used during design: [ambientCG Metal012](https://ambientcg.com/view?id=Metal012), [Poly Haven Blue Metal Plate](https://polyhaven.com/a/blue_metal_plate), [Metal Plate 02](https://polyhaven.com/a/metal_plate_02), [Rusty Metal 02](https://polyhaven.com/a/rusty_metal_02). CC0 material sources; preserve provenance. Raw texture archives are not needed in the repository if already embedded. Do not imply a license for the final artwork beyond the owner's decision.

For firmware, export a separately optimized logo at native display size after measuring RAM/flash requirements. Never embed the full SVG in watch firmware without conversion.
